# Calculator 🧮

A simple and interactive calculator built using HTML, CSS, and JavaScript. It performs basic arithmetic operations with a clean and user-friendly interface.

## 🚀 Live Demo

[Try the Calculator](https://sk-calci.netlify.app/)

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## ✨ Features

- Addition, subtraction, multiplication, and division
- Clear and delete functionality
- Interactive calculator buttons
- Responsive user interface
- Real-time calculation display

## 📚 What I Learned

- DOM manipulation using JavaScript
- Handling click events
- Performing arithmetic operations
- Styling layouts using CSS
- Building an interactive web application
